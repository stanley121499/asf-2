# 从零到一开网店：大概要花多少钱？（含请人帮忙做）

**更新：** 2026 年 4 月  
**写给谁看：** 五十岁上下、想先心里有个数再决定的老板或负责人。  
**重要：** 下面的数字是**参考区间**，不是合同报价。官网、外包、汇率**随时会变**，付钱前请再确认。

---

## 一、先弄懂：「从零到一」的钱通常分几袋？

很多人只问「做网站多少钱」，其实至少要分**五袋钱**（有的可以合并、有的会省掉）：


| 钱袋                | 白话                     | 常见情况                                                                                                         |
| ----------------- | ---------------------- | ------------------------------------------------------------------------------------------------------------ |
| **1. 域名**         | 网址名字，例如 `您的店.com`      | 每年付一次，几十到一百多马币很常见（看后缀 `.com` / `.com.my` 等）。                                                                 |
| **2. 主机或平台月租**    | 网站「租地方住」或 Shopify 那种月费 | WordPress 要另买主机；**Shopify / Wix** 多为美金月费；**EasyStore、SiteGiant** 等马来西亚常见 SaaS 多为**马币**，常强调虾皮/Lazada 同步与本地支付。 |
| **3. 请人建站、装修、上架** | 找设计师或程序员帮您搭好           | **本文重点**：Fiverr、Upwork、马来西亚本地公司，价钱差很多。                                                                       |
| **4. 主题、插件、应用**   | 漂亮版型、额外功能              | 有的免费，有的要**美金**买断或每年续费；外包报价**常常不含**您后来买的付费主题。                                                                 |
| **5. 收款与物流对接**    | 接 FPX、电子钱包、快递          | 开户有的免费、有的收安装费或月费；具体问 **iPay88、Stripe、PayPal** 等官方或代理。                                                        |


**记一句就好：** 外包报给您的一口价，通常只盖住其中几袋；要问清楚**包不包**域名、主机、商品照片处理、马来文/英文文案、后续改稿。

## 二、算马币时怎么换算？

很多网站用 **美元（USD）** 标价。下面举例用 **1 美元 ≈ 4.4 马币**（仅方便心算；您刷卡时以银行为准，一般在 **4.2～4.5** 之间浮动）。

**例子：** 外包收 **USD 200** → 大约 **RM 880**（未计平台手续费、未计税）。

## 三、网上找人做：Fiverr（2026 年 4 月前后行情）

**Fiverr 是什么：** 外国人很多，标价多是 **美金**；有人接「整套 Shopify 店」「整套 WordPress 网店」。  
**我们怎么查的：** 2026 年 4 月浏览 Fiverr 上「Shopify store setup」「WooCommerce / WordPress ecommerce」类服务，看**标价起点**和常见套餐，**不是**帮您挑卖家。

### 3.1 Shopify 店铺搭建（外包劳务，不含 Shopify 月租）

在 Fiverr 上，类似服务**标价**大致落在下面区间（**美元**）：


| 档位（白话）       | 您大概能期待什么                         | 常见标价起点（约）                              |
| ------------ | -------------------------------- | -------------------------------------- |
| **最便宜的一档**   | 极简：少量页面、少量商品、模板套一套               | 大约 **USD 40～100** 起（再低的也有，要仔细看评价与包含项目） |
| **中间档**      | 多几页、十几～几十样商品、付款与物流基础设置、有时含简单追踪代码 | 大约 **USD 100～250** 起                   |
| **偏高 / 工作室** | 强调品牌感、定制多、或写明「全案」                | 大约 **USD 250～500+** 起；再高的也有            |


**Fiverr 上也会用欧元显示：** 例如「From €72 / €134 / €427」——换算成马币请用当天汇率，概念上仍是「便宜档 / 中档 / 工作室档」。

**您一定要问清楚的：**

- 包不包含 **Shopify 自己的月租**（通常**不包含**，要您自己付给 Shopify）。  
- 包不包含 **付费主题**、**付费应用**（常常要您另买）。  
- 商品图、文案是谁写？上架 **几样** 算在价钱里？  
- 马来西亚常用的 **FPX / 本地支付** 会不会帮您接到能用？（很多海外卖家熟悉 PayPal、Stripe，本地要问清。）

**自行再查：** [Fiverr — Shopify store setup 服务列表](https://www.fiverr.com/gigs/shopify-store-setup)

### 3.2 WordPress + WooCommerce 网店（外包劳务，不含主机）

Fiverr 上「WordPress + WooCommerce 电商站」常见情况：


| 档位       | 约略起点（美元）          | 说明                      |
| -------- | ----------------- | ----------------------- |
| 简单建站套餐   | **USD 80～150** 起  | 页数少、商品少、模板化             |
| 完整一些的店   | **USD 125～300** 起 | 更多商品、插件、速度或 SEO 优化写入文案里 |
| 更复杂 / 定制 | **USD 300～800+**  | 看功能多少                   |


有卖家单独卖「只安装 WooCommerce」类服务，标价也可能 **USD 150** 左右起，但通常还要您先有主机和 WordPress。

**Fiverr 官方文章参考（英文）：** 曾提到请 WordPress 开发者 **每小时约 USD 20～250** 都有，差距来自经验与国家；见 [Fiverr — WordPress developer cost 指南](https://www.fiverr.com/resources/guides/programming-tech/wordpress-developer-cost)。

**自行再查：** [Fiverr — WooCommerce development 分类](https://www.fiverr.com/categories/programming-tech/website-development/woocommerce-development)

## 四、网上找人做：Upwork（2026 年前后常见说法）

**Upwork 是什么：** 也是全球外包平台；很多人用 **按小时** 计费，也有 **固定总价** 项目。

- **WordPress 开发者：** Upwork 公开资料曾写常见区间大约 **USD 15～28 / 小时** 为中位附近（会因经验、国家而变）。见 [Upwork — WordPress developers cost](https://www.upwork.com/hire/wordpress-developers/cost/)。  
- **WooCommerce：** 平台上可见的简介里，常见有 **USD 35～85 / 小时** 一类的报价（个案差很大）。

**心算例子（粗估）：**  
若一个简单 WooCommerce 店要 **20～40 小时** 人工，按 **USD 25 / 小时** 粗算 → **USD 500～1000**（约 **RM 2200～4400**），这还不含主机、付费插件、域名。

**自行再查：** [Upwork — Hire WooCommerce developers](https://www.upwork.com/hire/woocommerce-developers/)

## 五、其他常见平台（一笔带过）

- **Freelancer.com、PeoplePerHour** 等：逻辑类似 Fiverr / Upwork，标价同样要看国家、评价、是否含售后。  
- **马来西亚本地 Facebook 群组、小红书、朋友介绍：** 有时比国际平台好沟通，但**一定要签合同或书面约定**范围与修改次数。

没有哪一个平台保证「最便宜又最好」，要看**评价、沟通、是否做过马来西亚收款**。

## 七、平台月租也要算进去（否则总账会少算）

下面分**国际平台**和**马来西亚本地 SaaS**。**EasyStore** 以官网摘录为准；**SiteGiant** 官网较少公开明码，文中**第三方摘要价**务必向 **SiteGiant 销售**书面确认。

### 7.1 国际常见路线（美元为主）


| 路线               | 月租大概量级                                           | 说明                                                                                       |
| ---------------- | ------------------------------------------------ | ---------------------------------------------------------------------------------------- |
| **Shopify**      | 入门约 **USD 25/月** 起（年付可能略低）；更高方案 **USD 65、399** 等 | 马来西亚多数**不能用** Shopify 自家收款，要接第三方网关；Shopify 还可能对第三方网关**加收比例**。详见 [shopify.md](shopify.md) |
| **Wix 电商**       | 第三方摘要常写约 **USD 27～39/月** 量级（年付）                  | 见 [other-saas-wix-squarespace-bigcommerce.md](other-saas-wix-squarespace-bigcommerce.md) |
| **WordPress 主机** | 共享主机常 **USD 5～25/月** 量级；管理型 WordPress 可能更高       | 另加 WooCommerce 本身免费，但**安全、备份、速度**可能要付费插件                                                 |


### 7.2 马来西亚本地 SaaS：EasyStore 与 SiteGiant（马币）

**适合谁：** 想**马币标价**、要接**虾皮 / Lazada / TikTok Shop**、本地快递与支付，又不想自己搭 WordPress 的店主。两者都可**先免费试用或约演示**，再决定；详细功能对比见 [malaysia-local-platforms.md](malaysia-local-platforms.md)。

#### EasyStore（官网有标价 — 2026 年初本资料夹摘录）

官网：**[easystore.co/en-my/pricing](https://www.easystore.co/en-my/pricing)**  


| 方案（英文名）  | 页面上「月付」参考                       | 页面上「年付折算每月」参考                       |
| -------- | ------------------------------- | ----------------------------------- |
| Standard | **RM 249 / 月**                  | **RM 199 / 月**                      |
| Business | **RM 499 / 月**                  | **RM 399 / 月**                      |
| Growth   | 页面有划线促销式标价，曾显示约 **RM 497/月** 一带 | 年付栏也曾显示约 **RM 497/月** — **以您结账时为准** |
| Success  | **RM 1,199 / 月**                | **RM 999 / 月**                      |


**白话：** 入门若按年付折合 **RM 199/月** 起跳；要做齐门市 POS、进阶营销，方案会到 **几百～近千马币/月**。官网写订阅费外仍要付**支付网关**手续费（与「平台不收交易抽成」类说法要对照条款理解）。

#### SiteGiant（马来西亚老牌，偏「多平台卖货 + 营运」）

官网：**[sitegiant.my](https://sitegiant.my/)**  

公开营销上常强调：**网店版型**、**多市场同步**、**ERP / 仓库 / 门市 POS** 等模块（可依规模加购）。  

**价钱怎么查：** 不少方案是**按年付费**，且跟**每月订单量、SKU 数量、员工账号数**挂钩；**ERP、WMS** 大企业模块通常要**单独报价**。  

**第三方评论里曾出现的「网店方案」参考（非官网原价，仅帮您估区间）：**


| 档位（名称来自第三方摘要） | 约合每月（马币）     | 您该怎么用这个数字                     |
| ------------- | ------------ | ----------------------------- |
| Mini          | 约 **RM 105** | **不要当合同价**；向 SiteGiant 要最新报价单 |
| Basic         | 约 **RM 155** | 同上                            |
| Pro           | 约 **RM 175** | 同上                            |


**和 EasyStore 怎么选（一句白话）：** 两边都适合**重度虾皮/Lazada** 卖家；SiteGiant 产品线更偏**营运加深**（ERP、仓库等），实施与培训时间有时更长；**务必自己试用 + 问清续约与限制**。

## 八、「从零到一」总账怎么粗算？（四种常见路线）

下面是 **第一年粗账**（**不是**精确报价），帮您开会时心里有底：

### 路线 A：Shopify + Fiverr 外包（国际卖家）


| 项目                                    | 粗算                                    |
| ------------------------------------- | ------------------------------------- |
| Shopify 月租（12 个月，用 Basic 约 USD 25 举例） | 约 **USD 300**（≈ **RM 1,320**）         |
| Fiverr 建站（取中档约 USD 150～250）           | 约 **USD 150～250**（≈ **RM 660～1,100**） |
| 域名                                    | 约 **RM 50～150/年**                     |
| 付费主题或应用（不一定需要）                        | **USD 0～300+**                        |
| 支付网关（开户/费率另议）                         | 视供应商                                  |


**粗算合计（仅平台+外包+域名，不含进货）：** 大约 **RM 2,000～4,000+** 可以启动一个很基础的店；若要精品设计、很多应用，**轻松再往上**。

### 路线 B：WordPress + WooCommerce + 马来西亚本地套餐（含首年主机）


| 项目                                 | 粗算                          |
| ---------------------------------- | --------------------------- |
| 本地套餐（举例 RM 2,700～4,300，已常含首年主机与域名） | **RM 2,700～4,300**          |
| 第二年起主机与域名续约                        | 常 **RM 500～2,000/年**（看对方套餐） |
| 付费插件（SEO、缓存、备份等）                   | **RM 0～1,000+/年**           |


**粗算合计：** 第一年 **RM 3,000～6,000** 很常见；后续每年维护要留预算。

### 路线 C：EasyStore（本地 SaaS，马币订阅）


| 项目                            | 粗算                                             |
| ----------------------------- | ---------------------------------------------- |
| 平台费（举例：年付折合 **RM 199/月 ×12**） | 约 **RM 2,400/年**（选 Business、Success 会**明显更高**） |
| 域名                            | 部分活动或套餐可能送；否则 **RM 50～150/年** 自行注册             |
| 请人「美化、搬商品、教您用、接网关」            | **RM 1,000～5,000+** 或按小时，看范围                   |


**合计感觉：** 第一年若只做 Standard、自己又会上架，**RM 2,500～4,000** 也可能够；若要外包全程或升方案，**往上加**。

### 路线 D：SiteGiant（本地 SaaS，常按年付 — 价要向销售确认）


| 项目                                        | 粗算                                      |
| ----------------------------------------- | --------------------------------------- |
| 网店方案（用**第三方摘要**「约 RM 105～175/月」×12 仅作区间感） | 约 **RM 1,260～2,100/年** 量级 — **务必拿官方报价** |
| ERP / 仓库 / 多店                             | 常**另计**，可能 **数千～数万马币/年** 或项目制           |
| 请人培训、上货、对接                                | **RM 1,500～8,000+** 看复杂度；多市场同步越细，工越多    |


**合计感觉：** 若只是**入门网店档**且报价接近第三方写的年付水平，第一年**可能比 EasyStore Standard 略省一点订阅**，但**限制条件**（订单数、SKU、账号）要先问清；一旦加 **ERP/WMS**，总账会**跳一大截**。

**本地 SaaS 小结：** EasyStore 与 SiteGiant 都适合**不想折腾主机**、又要**马来西亚通路**的店主；**月租（或年摊）通常高于便宜 WordPress 主机，但常省下插件钱和接虾皮的时间**；建议用 **五年总账**（订阅 + 外包 + 网关费）和路线 A、B 比一比。

## 九、给长辈读者的防骗清单（很短）

1. **书面写清：** 做几页、上几个商品、改几次、保多久。
2. **钱分阶段付：** 不要一次付清全款，留尾款验收。
3. **账号归您：** Shopify / 域名、主机后台，最终要能**改密码掌握在您手里**。
4. **便宜过头要小心：** 异常低价常常不含您真正要的功能，后面加钱加不完。
