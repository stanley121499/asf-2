# Source: Expo customer home revamp plan (2026-07-16)

**Raw:** [2026-07-16-expo-customer-home-revamp-plan.md](../../raw/sources/2026-07-16-expo-customer-home-revamp-plan.md)

## Summary

Plan to revamp `asf-customer-app` Home: tenant-configurable **MODEL MATCH** brand, shorter shop-biased hero, horizontal new arrivals, all-active promo strip, once-per-session ceremony (motion + haptic). Assumes worst-case “no urge” (app specialness + purchase pull). Expo-only; no web parity in this program.

## Key locked decisions

- Brand: MODEL MATCH via `tenantBrand` module (tenant-configurable later)
- Offers: all active promos
- Ceremony: once per session
- Worst-case urge feedback
